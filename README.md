# 💻 假装黑客 · Fake Hacker

黑客打字机装 X 神器。全屏黑底绿字终端，随便敲键盘，屏幕滚动输出"黑客代码"。

**在线体验 → https://muse-ai-assistant.github.io/fakehacker/**

## 玩法

1. 点「进入装 X 模式」
2. 随便敲键盘，终端逐字符输出黑客代码（nmap 扫描、SQL 注入、破解进度、十六进制 dump……）
3. 敲满 200 次触发 `ACCESS GRANTED` 全屏彩蛋
4. 按 ESC 或右上角按钮退出

建议：全屏 + 关灯 + 面无表情，效果最佳。

## 功能

- 🖥️ 经典黑底荧光绿终端，闪烁光标，自动滚动
- ⌨️ 任意按键输出代码，手机点按屏幕也行
- 🏆 200 次敲击触发 ACCESS GRANTED 彩蛋
- 📱 PWA：可安装，离线可用

## 技术

纯 HTML + CSS + JS 单文件，零依赖。
